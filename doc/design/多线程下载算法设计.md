## 1. 三种方案对比

| 维度 | aria2 | PCL2 | 本方案 |
|------|-------|------|--------|
| 并发模型 | epoll 事件循环 + 命令队列 | 线程池 + 20ms 轮询 | 异步协程 (asyncio) |
| 切片方式 | 预切固定 Piece (1 MiB) | 动态切最长碎片 40% | 预切 + 动态再平衡 |
| 写盘 | 直接 pwrite + WrDiskCache | 每线程 .tmp → 合并 | 直接 pwrite + 写缓冲 |
| 慢线程处理 | 超时踢出 + 镜像切换 | 5s 无数据断开 | 三层检测 + 工作窃取 |
| 限速 | 禁用 IO 等待 | 令牌桶 | 令牌桶 |
| 续传 | .aria2 控制文件 + 段 memo | 线程级断点 | 段级 memo + 控制文件 |
| 多源 | 镜像速度统计切换 | 源轮转 + 降级 | 源轮转 + 失败禁用 |

## 2. aria2 核心算法

### 2.1 架构

```
DownloadEngine (epoll 主循环)
    └── Command 队列（CreateRequest → Connect → HttpRequest → HttpResponse → HttpDownload）
            └── SegmentMan（中央段调度器）
                    └── PieceStorage（位图管理）
                            └── DiskAdaptor（pwrite 落盘）
```

### 2.2 切片策略

- **Piece 大小**：默认 1 MiB，文件按 pieceLength 等分
- **并发数**：`split` 选项（默认 5），一次性创建 N 条连接
- **最小碎片**：`min-split-size` = 1 MiB，小于此值不再切分
- **段选择**：`StreamPieceSelector` 支持 default / inorder / geom / random

### 2.3 Range 请求

```
第一条请求：不带 Range（探针，获取 Content-Length + 判断是否支持 Range）
后续请求：Range: bytes={start}-{end}（精确字节区间）
```

### 2.4 写盘

- `SinkStreamFilter` → `WrDiskCache`（16 KiB 子块合并写）→ `pwrite` 到偏移
- 各段区间不重叠，天然并发安全

### 2.5 异常处理

| 异常 | 行为 |
|------|------|
| `DlAbortEx` | 移除 URI，不重试 |
| `DlRetryEx` | 计数，超 `max-tries` 放弃，否则重新建连 |
| `DownloadFailureException` | 整组停止 |

段取消时记录 `segmentWrittenLengthMemo_[index] = written`，下次 checkout 从断点继续。

### 2.6 慢线程应对

- 超时检测 → 踢出 → 段归还
- `findFasterRequest`：周期性比较 `PeerStat.avgDownloadSpeed`，切换到更快镜像
- **不足**：慢连接"活着但慢"时不会被主动抢走

## 3. PCL2 核心算法

### 3.1 架构

```
NetManagerClass（全局管理器，两个 20ms 轮询线程）
    └── LoaderDownload（任务包装器）
            └── NetFile（单文件，维护线程链表）
                    └── NetThread（单线程，负责一个字节区间）
```

### 3.2 动态切片

```vb
' 核心：TryBeginThread()
1. 首个线程：从 0 开始，不带 Range（探测大小）
2. 失败续传：找已取消线程的断点继续
3. 动态扩碎片：找 DownloadUndone 最大的线程，从末尾往前 40% 处切开
   StartPosition = FilePieceMax.DownloadEnd - FilePieceMax.DownloadUndone * 0.4
4. 最小碎片保护：DownloadUndone < 256KB 时不再拆分
```

### 3.3 动态线程数

- 全局速度 < `NetTaskSpeedLimitLow` 时追加线程
- 准备中线程数 ≤ 下载中线程数（防突发）
- 每线程启动延迟 `i × 250ms`

### 3.4 多源容错

- 源列表轮转，失败计数超限 → 禁用
- 全部源失败 → 降级为单线程模式 → 全量重试一次
- 416/502/404 → 立即禁用源

### 3.5 限速（令牌桶）

```vb
' 每 100ms 补充 High/10 的令牌
' 写数据前：While 余量 <= 0 → Sleep(16)
' 写数据后：余量 -= 实际字节数
```

### 3.6 慢线程应对

- `DeltaTime > 5000ms && DeltaTime > RealDataCount` → 强制断开
- 切最大碎片（但只看剩余量，不看速度）
- **不足**：快线程完成后直接退出，不会帮慢线程

## 4. 本方案设计

### 4.1 总体架构

```
┌─────────────────────────────────────────────────────────┐
│                  DownloadEngine (asyncio)                 │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │         WorkStealingScheduler                    │    │
│  │  - 段分配 / 归还 / 窃取                         │    │
│  │  - 速度采样管理                                  │    │
│  │  - 慢线程检测器                                  │    │
│  └─────────────────────────────────────────────────┘    │
│           │              │              │               │
│           ▼              ▼              ▼               │
│     Worker-0       Worker-1  ...   Worker-N             │
│     (协程)         (协程)          (协程)               │
│           │              │              │               │
│           ▼              ▼              ▼               │
│     pwrite(off_0)  pwrite(off_1)  pwrite(off_N)        │
│     [区间不重叠，天然并发安全]                           │
│                                                         │
│  ┌──────────────┐  ┌──────────────┐                    │
│  │ TokenBucket  │  │ SourceManager│                    │
│  │ (限速)       │  │ (多源轮转)   │                    │
│  └──────────────┘  └──────────────┘                    │
└─────────────────────────────────────────────────────────┘
```

### 4.2 切片策略

1. **探测**：HEAD 请求获取 `Content-Length` + `Accept-Ranges`
2. **预切**：`total / split_count`，每段 ≥ `min_split_size`
3. **动态再平衡**：快线程完成后从最慢段尾部切 40%
4. **小文件保护**：`total < min_split × 2` 时不拆分

### 4.3 工作窃取机制

```
快线程完成自己的段
     │
     ▼
还有无主段？──Yes──→ 正常分配
     │No
     ▼
找速度最慢的段（avg speed 最低）
     │
     ▼
剩余 > 2×min_split？──No──→ 退出
     │Yes
     ▼
从尾部切 40% 给快线程
原慢线程继续拉前半部分（end 被缩小，无感知）
```

### 4.4 慢线程三层检测

```
Layer 1 - 绝对阈值：my_avg < median(peers) × 0.3
Layer 2 - 持续确认：连续 3 个周期（1.5s）低于阈值
Layer 3 - P10 尾部确认：该线程的 P10 分位数也低于阈值
三层全过 → KILL
```

### 4.5 写盘

- 预分配文件（`os.ftruncate`）
- 各 Worker 直接 `pwrite` 到自己的偏移
- 写缓冲 64 KB，攒满刷盘

### 4.6 限速

- 全局令牌桶，10ms 粒度
- 最多攒 1 秒令牌（防突发）

## 5. 完整 Python 实现

```python
"""
多线程下载器 - 完整实现
特性：异步协程 + 工作窃取 + 慢线程检测 + 令牌桶限速 + 多源容错
"""

import asyncio
import aiohttp
import os
import time
import statistics
from collections import deque
from dataclasses import dataclass, field
from typing import Optional, List, Dict
from enum import Enum


# ═══════════════════════════════════════════════════════════
# 配置
# ═══════════════════════════════════════════════════════════

@dataclass
class DownloadConfig:
    split: int = 5                    # 初始并发连接数
    min_split_size: int = 256 * 1024  # 最小碎片 256 KB
    chunk_size: int = 64 * 1024       # 每次读取 64 KB
    write_buffer_size: int = 64 * 1024  # 写缓冲 64 KB
    sample_interval: float = 0.5      # 速度采样间隔 500ms
    speed_window: int = 20            # 速度滑动窗口大小（= 10秒）
    slow_ratio: float = 0.3           # 低于中位数 30% 视为慢
    slow_confirm: int = 3             # 连续 3 次确认
    slow_min_samples: int = 6         # 至少 6 个采样才判定
    grace_period: float = 2.0         # 新线程宽限期 2 秒
    steal_ratio: float = 0.4          # 窃取比例 40%
    max_retries: int = 3              # 单段最大重试
    rate_limit: float = -1            # 限速 (bytes/s)，-1 不限
    timeout: float = 30.0             # 连接超时


# ═══════════════════════════════════════════════════════════
# 段 (Segment)
# ═══════════════════════════════════════════════════════════

class SegmentState(Enum):
    PENDING = "pending"
    DOWNLOADING = "downloading"
    COMPLETE = "complete"
    CANCELLED = "cancelled"


@dataclass
class Segment:
    seg_id: int
    start: int              # 全局起始偏移
    end: int                # 全局结束偏移（exclusive）
    written: int = 0        # 已写字节数
    owner_id: int = -1      # 所属 worker
    state: SegmentState = SegmentState.PENDING
    retries: int = 0
    speed_history: deque = field(default_factory=lambda: deque(maxlen=20))

    @property
    def remaining(self) -> int:
        return self.end - (self.start + self.written)

    @property
    def position_to_write(self) -> int:
        return self.start + self.written

    @property
    def is_complete(self) -> bool:
        return self.written >= (self.end - self.start)

    @property
    def avg_speed(self) -> float:
        if len(self.speed_history) < 2:
            return float('inf')
        return statistics.mean(self.speed_history)

    @property
    def p10_speed(self) -> float:
        """P10 分位数 - 类比 1% Low"""
        if len(self.speed_history) < 5:
            return float('inf')
        sorted_h = sorted(self.speed_history)
        idx = max(0, int(len(sorted_h) * 0.1))
        return sorted_h[idx]

    def record_speed(self, speed: float):
        self.speed_history.append(speed)


# ═══════════════════════════════════════════════════════════
# 令牌桶限速器
# ═══════════════════════════════════════════════════════════

class TokenBucket:
    def __init__(self, rate: float):
        """rate: bytes/sec, -1 表示不限速"""
        self.rate = rate
        self.tokens = 0.0
        self.last_refill = time.monotonic()
        self._lock = asyncio.Lock()

    async def consume(self, n_bytes: int):
        if self.rate <= 0:
            return
        async with self._lock:
            while True:
                self._refill()
                if self.tokens >= n_bytes:
                    self.tokens -= n_bytes
                    return
                deficit = n_bytes - self.tokens
                wait_time = deficit / self.rate
                await asyncio.sleep(min(wait_time, 0.01))

    def _refill(self):
        now = time.monotonic()
        elapsed = now - self.last_refill
        self.tokens += elapsed * self.rate
        self.tokens = min(self.tokens, self.rate)  # 最多攒 1 秒
        self.last_refill = now


# ═══════════════════════════════════════════════════════════
# 慢线程检测器
# ═══════════════════════════════════════════════════════════

class SlowThreadDetector:
    """
    三层判定：
      Layer 1: my_avg < median(peers) × ratio_threshold
      Layer 2: 连续 confirm_count 个周期低于阈值
      Layer 3: P10 也低于阈值（排除偶尔慢）
    """

    def __init__(self, config: DownloadConfig):
        self.ratio = config.slow_ratio
        self.confirm_count = config.slow_confirm
        self.min_samples = config.slow_min_samples
        self.grace_period = config.grace_period
        self.strikes: Dict[int, int] = {}
        self.birth_time: Dict[int, float] = {}

    def register(self, worker_id: int):
        self.birth_time[worker_id] = time.monotonic()
        self.strikes[worker_id] = 0

    def evaluate(self, worker_id: int, segment: Segment,
                 all_segments: List[Segment]) -> str:
        """返回 'healthy' | 'warning' | 'kill'"""

        # 宽限期
        age = time.monotonic() - self.birth_time.get(worker_id, 0)
        if age < self.grace_period:
            return 'healthy'

        # 样本不足
        if len(segment.speed_history) < self.min_samples:
            return 'healthy'

        # Layer 1: 计算基准线（其他段的中位速度）
        peer_speeds = [s.avg_speed for s in all_segments
                       if s.owner_id != worker_id
                       and s.owner_id != -1
                       and s.state == SegmentState.DOWNLOADING
                       and len(s.speed_history) >= self.min_samples]
        if not peer_speeds:
            return 'healthy'

        baseline = statistics.median(peer_speeds)
        if baseline <= 0:
            return 'healthy'

        threshold = baseline * self.ratio
        if segment.avg_speed >= threshold:
            self.strikes[worker_id] = 0
            return 'healthy'

        # Layer 2: 持续确认
        self.strikes[worker_id] = self.strikes.get(worker_id, 0) + 1
        if self.strikes[worker_id] < self.confirm_count:
            return 'warning'

        # Layer 3: P10 尾部确认
        if segment.p10_speed < threshold:
            return 'kill'

        return 'warning'


# ═══════════════════════════════════════════════════════════
# 工作窃取调度器
# ═══════════════════════════════════════════════════════════

class WorkStealingScheduler:
    def __init__(self, total_size: int, config: DownloadConfig):
        self.config = config
        self.total_size = total_size
        self.segments: List[Segment] = []
        self.detector = SlowThreadDetector(config)
        self._lock = asyncio.Lock()
        self._seg_counter = 0
        self._complete_event = asyncio.Event()

        self._initial_split(total_size)

    def _initial_split(self, total_size: int):
        split = self.config.split
        min_size = self.config.min_split_size

        if total_size < min_size * 2:
            split = 1

        seg_size = total_size // split
        while seg_size < min_size and split > 1:
            split -= 1
            seg_size = total_size // split

        for i in range(split):
            start = i * seg_size
            end = (i + 1) * seg_size if i < split - 1 else total_size
            self.segments.append(Segment(
                seg_id=self._seg_counter,
                start=start, end=end
            ))
            self._seg_counter += 1

    async def checkout(self, worker_id: int) -> Optional[Segment]:
        """正常分配：拿一个无主段"""
        async with self._lock:
            for seg in self.segments:
                if seg.state == SegmentState.PENDING and seg.remaining > 0:
                    seg.state = SegmentState.DOWNLOADING
                    seg.owner_id = worker_id
                    self.detector.register(worker_id)
                    return seg
        return None

    async def steal_or_checkout(self, worker_id: int) -> Optional[Segment]:
        """工作窃取：先拿无主段，没有则从最慢段尾部切"""
        seg = await self.checkout(worker_id)
        if seg:
            return seg

        async with self._lock:
            slowest = self._find_slowest(exclude=worker_id)
            if slowest and slowest.remaining > self.config.min_split_size * 2:
                cut_size = int(slowest.remaining * self.config.steal_ratio)
                cut_point = slowest.end - cut_size

                new_seg = Segment(
                    seg_id=self._seg_counter,
                    start=cut_point,
                    end=slowest.end,
                    owner_id=worker_id,
                    state=SegmentState.DOWNLOADING
                )
                self._seg_counter += 1
                slowest.end = cut_point  # 缩小原段
                self.segments.append(new_seg)
                self.detector.register(worker_id)
                return new_seg

        return None

    def _find_slowest(self, exclude: int) -> Optional[Segment]:
        candidates = [s for s in self.segments
                      if s.owner_id != exclude
                      and s.owner_id != -1
                      and s.state == SegmentState.DOWNLOADING
                      and s.remaining > self.config.min_split_size]
        if not candidates:
            return None
        return min(candidates, key=lambda s: s.avg_speed)

    async def complete(self, seg: Segment):
        async with self._lock:
            seg.state = SegmentState.COMPLETE
            seg.owner_id = -1
            if self.all_done():
                self._complete_event.set()

    async def cancel(self, seg: Segment):
        """慢线程被杀后，段归还"""
        async with self._lock:
            seg.state = SegmentState.PENDING
            seg.owner_id = -1
            seg.speed_history.clear()

    def all_done(self) -> bool:
        return all(s.state == SegmentState.COMPLETE or s.remaining <= 0
                   for s in self.segments)

    async def wait_complete(self):
        await self._complete_event.wait()


# ═══════════════════════════════════════════════════════════
# 多源管理器
# ═══════════════════════════════════════════════════════════

@dataclass
class Source:
    url: str
    fail_count: int = 0
    is_failed: bool = False
    max_fails: int = 5


class SourceManager:
    def __init__(self, urls: List[str]):
        self.sources = [Source(url=u) for u in urls]
        self._idx = 0

    def get_source(self) -> Optional[Source]:
        for _ in range(len(self.sources)):
            src = self.sources[self._idx % len(self.sources)]
            self._idx += 1
            if not src.is_failed:
                return src
        return None

    def report_failure(self, source: Source):
        source.fail_count += 1
        if source.fail_count >= source.max_fails:
            source.is_failed = True

    def report_success(self, source: Source):
        source.fail_count = max(0, source.fail_count - 1)


# ═══════════════════════════════════════════════════════════
# Worker（下载协程）
# ═══════════════════════════════════════════════════════════

class DownloadWorker:
    def __init__(self, worker_id: int, file_path: str,
                 scheduler: WorkStealingScheduler,
                 source_mgr: SourceManager,
                 limiter: TokenBucket,
                 config: DownloadConfig):
        self.worker_id = worker_id
        self.file_path = file_path
        self.scheduler = scheduler
        self.source_mgr = source_mgr
        self.limiter = limiter
        self.config = config
        self._write_buf = bytearray()
        self._buf_offset = 0

    async def run(self, session: aiohttp.ClientSession):
        while True:
            seg = await self.scheduler.steal_or_checkout(self.worker_id)
            if seg is None:
                return  # 全部完成

            success = await self._download_segment(session, seg)
            if success:
                await self.scheduler.complete(seg)
            else:
                seg.retries += 1
                if seg.retries < self.config.max_retries:
                    await self.scheduler.cancel(seg)
                else:
                    await self.scheduler.cancel(seg)

    async def _download_segment(self, session: aiohttp.ClientSession,
                                seg: Segment) -> bool:
        source = self.source_mgr.get_source()
        if not source:
            return False

        start = seg.position_to_write
        end = seg.end - 1
        headers = {"Range": f"bytes={start}-{end}"}

        try:
            async with session.get(source.url, headers=headers,
                                   timeout=aiohttp.ClientTimeout(
                                       total=self.config.timeout)) as resp:
                if resp.status not in (200, 206):
                    self.source_mgr.report_failure(source)
                    return False

                last_tick = time.monotonic()
                tick_bytes = 0

                async for chunk in resp.content.iter_chunked(
                        self.config.chunk_size):
                    if not chunk:
                        break

                    # 限速
                    await self.limiter.consume(len(chunk))

                    # 写盘（带缓冲）
                    self._buffered_write(chunk, seg.position_to_write)
                    seg.written += len(chunk)
                    tick_bytes += len(chunk)

                    # 速度采样
                    now = time.monotonic()
                    dt = now - last_tick
                    if dt >= self.config.sample_interval:
                        speed = tick_bytes / dt
                        seg.record_speed(speed)
                        tick_bytes = 0
                        last_tick = now

                        # 慢线程检测
                        verdict = self.scheduler.detector.evaluate(
                            self.worker_id, seg, self.scheduler.segments)
                        if verdict == 'kill':
                            self._flush_buffer()
                            self.source_mgr.report_failure(source)
                            return False

                self._flush_buffer()
                self.source_mgr.report_success(source)
                return seg.is_complete

        except (asyncio.TimeoutError, aiohttp.ClientError, OSError):
            self._flush_buffer()
            self.source_mgr.report_failure(source)
            return False

    def _buffered_write(self, data: bytes, offset: int):
        if not self._write_buf:
            self._buf_offset = offset
        self._write_buf.extend(data)
        if len(self._write_buf) >= self.config.write_buffer_size:
            self._flush_buffer()

    def _flush_buffer(self):
        if self._write_buf:
            with open(self.file_path, "r+b") as f:
                f.seek(self._buf_offset)
                f.write(self._write_buf)
            self._write_buf.clear()


# ═══════════════════════════════════════════════════════════
# 主入口
# ═══════════════════════════════════════════════════════════

async def probe(url: str, session: aiohttp.ClientSession) -> tuple:
    """探测文件大小和 Range 支持"""
    async with session.head(url) as resp:
        total = int(resp.headers.get("Content-Length", -1))
        accept_ranges = resp.headers.get("Accept-Ranges", "none") != "none"
        return total, accept_ranges


async def download(urls, out_path: str, config: DownloadConfig = None):
    """
    主下载函数
    urls: 下载源列表（支持多源）或单个 URL 字符串
    out_path: 输出文件路径
    config: 下载配置
    """
    if config is None:
        config = DownloadConfig()

    url_list = urls if isinstance(urls, list) else [urls]
    source_mgr = SourceManager(url_list)

    async with aiohttp.ClientSession() as session:
        # 1. 探测
        total, accept_ranges = await probe(url_list[0], session)
        if total <= 0:
            raise ValueError("无法获取文件大小")

        # 2. 不支持 Range → 单流
        if not accept_ranges:
            config.split = 1

        # 3. 预分配文件
        with open(out_path, "wb") as f:
            f.truncate(total)

        # 4. 初始化组件
        scheduler = WorkStealingScheduler(total, config)
        limiter = TokenBucket(config.rate_limit)

        # 5. 启动 Workers
        workers = [
            DownloadWorker(i, out_path, scheduler, source_mgr, limiter, config)
            for i in range(config.split)
        ]
        tasks = [asyncio.create_task(w.run(session)) for w in workers]
        await asyncio.gather(*tasks)

    print(f"下载完成: {out_path} ({total} bytes)")


# ═══════════════════════════════════════════════════════════
# 使用示例
# ═══════════════════════════════════════════════════════════

if __name__ == "__main__":
    config = DownloadConfig(
        split=8,
        rate_limit=10 * 1024 * 1024,  # 10 MB/s 限速
        min_split_size=512 * 1024,     # 512 KB 最小碎片
    )

    asyncio.run(download(
        urls=["https://example.com/file.zip"],
        out_path="./file.zip",
        config=config
    ))
```

## 附录：算法参数速查

| 参数 | 默认值 | 说明 |
|------|--------|------|

| `slow_confirm` | 3 | 连续确认次数 |
| `grace_period` | 2 s | 新线程宽限期 |
| `steal_ratio` | 0.4 | 工作窃取切割比例 |
| `max_retries` | 3 | 单段最大重试 |
| `rate_limit` | -1 | 全局限速 (B/s)，-1 不限 |
